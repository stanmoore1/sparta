.. index:: timestep

timestep command
================

Syntax
""""""


.. code-block:: SPARTA

   timestep dt

* dt = timestep size (time units)

Examples
""""""""


.. code-block:: SPARTA

   timestep 2.0 
   timestep 0.003

Description
"""""""""""

Set the timestep size for subsequent simulations.

**Restrictions:** none

Related commands
""""""""""""""""

:doc:`run <run>`

Default
"""""""


.. code-block:: SPARTA

   timestep 1.0
