.. index:: uncompute

uncompute command
=================

Syntax
""""""


.. code-block:: SPARTA

   uncompute compute-ID

* compute-ID = ID of a previously defined compute

Examples
""""""""


.. code-block:: SPARTA

   uncompute 2
   uncompute lower-boundary

Description
"""""""""""

Delete a compute that was previously defined with a :doc:`compute <compute>`
command.

**Restrictions:** none

Related commands
""""""""""""""""

:doc:`compute <compute>`

**Default:** none
