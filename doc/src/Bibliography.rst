Bibliography
============

Every work cited in this manual, listed once, alphabetically by the key
the pages cite it by.  Each entry links to the pages that cite it; the
reference is also given at the bottom of each of those pages.

.. The entries below are generated when the manual is built, from the
   references at the bottom of each page (see conf.py), so this list
   cannot fall out of step with them.  Do not add entries here: add the
   reference to the page that cites it.
