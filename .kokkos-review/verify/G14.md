### F-G14-2

fix: systemic, preferred: in particle_kokkos.cpp move the k_species2group rebuild block (lines 965-970) out of wrap_kokkos() into a new `void ParticleKokkos::update_species2group()` and call it from UpdateKokkos::setup() unconditionally (after the prewrap block, update_kokkos.cpp ~366), so it is rebuilt every run after Mixture::init. Local alternative for this file only: in FixAveHistoKokkos::end_of_step (:150) replace `d_s2g = particle_kk->k_species2group.view_device();` with a per-call refresh of a member `DAT::tdual_int_2d k_s2g` sized (particle->nmixture, particle->nspecies) filled from particle->mixture[i]->species2group[j], modify_host/sync_device, then `d_s2g = k_s2g.view_device();` (same pattern as compute_reduce_kokkos.cpp:680-686).

### F-G14-4

reason: The branches that leave d_weights unset are (a) compute PERGRID j>0 with compute->array_grid NULL (:213) and (b) fix PERGRID with empty d_array_grid (:259). fix: none required (optional: reset `d_weights = decltype(d_weights)();` next to `weights = NULL;` at :122 for hygiene).
