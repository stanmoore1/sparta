### F-G04-1
VERDICT: CONFIRMED
reason: sparta.cpp:563 calls react->init() before each run; ReactBird::init (react_bird.cpp:112-113) zeroes only the host array tally_reactions (= k_tally_reactions.view_host().data()) without modify_host(). ReactBirdKokkos::init (react_bird_kokkos.cpp:98-155) never zeroes d_tally_reactions, and nothing else does (grep: only atomic_inc in react_tce/qk/tce_qk_kokkos.h, backup/restore copy). extract_tally (161-181) does modify_device()+sync_host() (or reduces the device view directly on gpu-aware path), so run-2 Finish tallies (finish.cpp:360) include run-1 counts. With a host-only build the device view aliases the host view so it is zeroed correctly; the bug manifests whenever device and host memory differ (GPU builds).
fix: in ReactBirdKokkos::init after ReactBird::init(), add `Kokkos::deep_copy(d_tally_reactions,0);` (and optionally `k_tally_reactions.modify_device();` / clear host modify flag) so device tallies reset each run, matching react_bird.cpp:113.
