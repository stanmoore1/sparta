## Caveats
- There was no GPU and no CUDA/HIP/SYCL compiler. Device-code legality was checked by reading, and
  host/device coherence with the split-memory tool. **The one remaining test worth doing is a build and
  an example run on a real GPU.**
- SYCL builds with an external Kokkos older than 4.5 no longer compile. The bundled Kokkos 5.2.2 is fine.
- `emit.surf.subsonic` executes 2.4% more instructions because a kernel is no longer inlined. Wall time is
  not measurably slower.

## Pre-existing bugs found, not fixed (same in `e071055f`)
- **Migrate-list overflow** in `update.cpp` and `update_kokkos.cpp`: the list is sized before the move, so
  it can overflow when surface reactions add many particles that leave the rank in the same step. It was
  only reproduced with an extreme input. **This is the one worth fixing.**
- `compute dt/grid`: the CPU style skips every cell at step 0, so its step-0 output differs from Kokkos.
- UBSan:
  - `qsort` called with a NULL list in `marching_cubes.cpp:934`
  - `memset(NULL,0,0)` in `surf_comm.cpp:94`
- Leaks at exit:
  - the `Python` object is not freed after `clear`
  - leaks on the watertight-check error exit
- Valgrind: uninitialised read in `Grid::update_halo_index`.
- The Kokkos 2d remap in collective mode crashes on MPI stubs. Nothing in SPARTA uses that mode.
