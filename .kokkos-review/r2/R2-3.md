# R2-3 (=FU-14) compute react/surf init() warning count depends on #ranks

## Root cause
ComputeReactSurf::init() counts group surfs with isr != this model by looping lines/tris[0..surf->nlocal).
For explicit/distributed surfs nlocal = surfs touching my owned grid cells, so a surf spanning cells on k
ranks is counted k times after the MPI_SUM -> count grows with #ranks (25/26/28 on np1/2/4, AB5 sibling).
Non-distributed: every rank has all nsurf, count kept local (no sum) -> already correct.
react/isurf/grid: implicit surfs, nlocal = surfs in owned cells only (ghosts at [nlocal,nlocal+nghost)),
each implicit surf belongs to exactly one cell -> expected rank-independent; to be verified.
Sibling candidate: Surf::init() (surf.cpp ~300-345) error counts "invalid type" (nlocal) and
"not assigned to a collision model" (nlocal+nghost!) with MPI_SUM for distributed -> rank-dependent count.
